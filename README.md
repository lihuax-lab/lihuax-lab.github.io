# 🌸 Lihuax Lab Website

Welcome to the official website of **Lihuax Lab**, powered by [Fuwari](https://github.com/saicaca/fuwari) – a minimalist, poetic static site generator for personal and research blogs.

This repository contains the source code of [lihuax-lab.github.io](https://lihuax-lab.github.io), deployed via GitHub Pages. It serves as a digital garden of thoughts, code, and research footprints.

---

## 🏡 About the Site

This site is a space for:

- 📚 Sharing technical notes and development logs
- 🧪 Presenting research projects in bioinformatics and related fields
- 🎐 Writing and reflection, from code to science to philosophy

It is built with simplicity and calm in mind — clean layout, fast loading, and elegant typography.

---

## 🚀 Getting Started

To run the site locally:

```bash
git clone https://github.com/lihuax-lab/lihuax-lab.github.io.git
cd lihuax-lab.github.io

# Install dependencies (use pnpm for best experience)
pnpm install

# Start development server
pnpm dev
```

To build the production site:

```bash
pnpm build
```

The output will be in the `dist/` folder, ready to be deployed to any static hosting service.
